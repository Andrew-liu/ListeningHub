Features

核心功能

从基础听读到精进复习，一站式覆盖语言学习全流程

01

真人原声 · 逐句时间轴

精选 VOA Learning English 新闻、健康、科技、历史、习语等 12 个栏目的真人播音（公有领域），用 Whisper 把官方文稿逐句对齐到音频，点哪句播哪句。也可以导入自己的音频 + LRC/SRT/VTT 字幕。

健康 科学 习语
02

逐句精听

每一句都能独立播放、循环、重听；0.6×～1.2× 变速不变调，连续播放时可开「逐句暂停」。按 H 把卡住的句子收进难句本，复习时专门再练。

Space 播放 ←→ 切换
03

中英双语对照

每句英文配备精准中文翻译，一键切换显示 / 隐藏。先听后看、边听边看、纯听力模式，灵活适配各阶段练习需求。

示例
Exercise is good for health.
锻炼有益于健康。
04

智能生词本

点击任意单词弹出音标、英美发音、中英释义；词光收录的词还会显示插画和辨析。收藏时连同原句一起保存，复习时能直接回放那一句真人原声。

exercise /ˈeksərsaɪz/
中 体育锻炼；运动
05

听写模式

只听音频写下每一个单词，系统即时对比评分。逐词高亮差异 · 0-100 分评估 · 训练拼写与听辨的绝佳方式。

exercise ✓ 正确　excersise ✗ 拼错
06

跟读模式

麦克风录制你的发音，与原音一键对比回放。模仿语音语调、节奏停顿，打磨真正地道的英语口语。

基于 MediaRecorder API · 浏览器原生录音
07

间隔重复复习 (SRS)

采用简化版 SM-2 算法，根据你对单词的熟练度，智能安排下次复习时间。记得牢、忘得慢。

忘记 困难 还行 熟练
08

个性化体验

三色主题（明亮 / 暗黑 / 复古）· PWA 可安装到桌面 · 首学五步完成后按 6h/1d/2d/4d/7d/14d/28d 自动排 7 轮复习 · Anki / CSV 导出生词（含原句）。

☀ Light ◐ Sepia ☾ Dark
09

背单词 · 词光雅思图鉴 + 拼写练习

新增词光 Word Atlas 雅思词库 7298 词：每词一幅插画、CEFR 分级、19 个话题、英美发音、两条例句朗读、搭配词族与辨析（CC BY 4.0）。另有初中 / 高中 / CET4 / CET6 / 考研 / 托福 / SAT 七大词库。拼写模式直接敲键盘逐字母练习，支持默写；拼写表现自动接入记忆曲线，错 3 次以上的词自动进生词本循环复习。

8 大词库 · 3.4 万词 ⌨ 拼写模式 👁 默写自测 记忆曲线 联动生词本
